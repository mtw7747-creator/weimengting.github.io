## 生成基准

- 场景母图：16 张，统一为 9:16 竖屏空镜或同构季节派生图。
- 道具与连续状态图：22 张；P01 吉他、P03 合同与P07设备按剧情阶段分别锁定。
- 车辆母图：1 张，无品牌、无可读车牌。
- 场景不含人物、动物、品牌、水印或剧情特效。
- 手机与电脑屏幕使用空白占位，新闻、账号与歌词等文字在后期使用 UI 贴图叠加。
- 合同母图重点锁定文件夹、页数、纸张和签字区；合同标题与正文不作为可读成片文字使用。

## LibTV 使用建议

1. 先在角色、场景、道具三个资产目录中锁定对应参考图。
2. 根据镜头节点从场景母图派生 A 建立、B 主拍、C 反打、D 细节四类首帧，不让模型重新设计空间。
3. 合同撕裂、签字笔滚动、手机亮屏等状态应作为剧情节点的派生图制作，不修改母图。
4. 所有可读中文统一作为 UI 或后期贴图处理，避免视频模型生成错字与乱码。
5. 新歌词MV节点优先调用本清单中的替换版；备份目录不得加入LibTV参考图池。
