# 咖逗 AI 宠物视频指令列表

项目：咖逗 AI 宠物视频指令体系  
周期：2025.05—2025.06  
用途：为宠物陪伴小程序整理可复用的动作生成指令，供后端接入视频生成服务。

> 这份文件展示项目中沉淀的提示词结构与代表性动作样例。实际生成时会根据模型、宠物图片和参数做小范围调整。

## 统一指令结构

```text
主体 + 固定背景 + 动作起点 + 动作过程 + 动作终点 + 镜头 + 速度/节奏 + 连续性约束 + 禁止项
```

### 固定约束

- 主体：保持同一只宠物的品种、毛色、脸部特征、项圈与体型。
- 背景：锁定原始场景、机位和主要物件，动作发生时背景不替换、不漂移。
- 动作：写清楚从哪里开始、经过哪些阶段、最后停在哪里。
- 镜头：先固定景别、机位和移动方向，再描述动作。
- 节奏：用慢速、自然速度或短暂停顿，避免模型自行加速。
- 连续性：动作必须连续完成，不跳帧、不瞬移、不改变主体。
- 禁止项：多余肢体、身体变形、宠物换色、镜头乱移、突然出现其他主体。

## 代表性动作样例

### 01｜跑步

```text
同一只黑白边牧在客厅里从画面左侧开始自然跑向右侧，先迈出后腿，随后前后腿交替摆动，身体重心随步伐轻微起伏，最后在沙发前减速停下。固定中景侧面机位，镜头平稳跟随，不切镜，不突然加速。保持边牧的黑白毛色、脸部花纹、体型和红色项圈不变。禁止身体拉伸、腿部增加、毛色漂移、瞬移和镜头抖动。
```

### 02｜跳跃

```text
同一只柯基站在客厅地面，先屈膝蓄力，再双脚离地向前跳起，身体在空中保持完整，随后自然落地并站稳。固定中景机位，完整拍到起跳、腾空和落地三个阶段，动作速度自然，不切镜。保持耳朵、白胸、脸部花纹和体型连续。禁止悬空停留、四肢变形、落地后滑动或出现第二只宠物。
```

### 03｜趴下

```text
同一只宠物从站立开始，先低头，再弯曲前腿和后腿，胸腹逐渐贴近地面，最后保持趴卧姿势看向镜头。固定正面中景，动作一气呵成，镜头不移动。保持主体比例、毛色和项圈连续。禁止突然倒下、身体穿透地面、腿部数量变化和面部变形。
```

### 04｜洗澡

```text
同一只宠物站在浴室防滑垫上，先看向水流，再轻轻低头，身体保持稳定，水从背部均匀流过，最后抬头看向镜头并轻微甩水。固定中景，动作节奏自然，保持浴室环境和主体位置不变。禁止水流遮挡整张脸、宠物变形、突然改变毛色、镜头切换和新增人物。
```

### 05｜打招呼

```text
同一只宠物坐在客厅地面，先保持坐姿看向镜头，再抬起右前爪轻轻挥动两次，最后放下前爪恢复坐姿。固定正面中景，镜头稳定，完整呈现抬爪、挥动和放下。保持眼睛、耳朵、脸部花纹、体型和项圈不变。禁止多出前爪、身体拉伸、表情突变和镜头乱移。
```

## 测试记录字段

| 字段 | 记录内容 |
| --- | --- |
| 动作名称 | 跑步 / 跳跃 / 趴下 / 洗澡 / 打招呼 |
| 输入图片 | 宠物角色资产图版本 |
| 生成路径 | 可灵 API / 火山引擎 API |
| 动作完整度 | 起点、过程、终点是否完整 |
| 主体稳定性 | 毛色、体型、脸部特征是否连续 |
| 镜头可用性 | 景别、机位、跟随是否稳定 |
| 可用结论 | 保留、修改或淘汰 |

## 交付方式

经过多轮生成测试后，只保留动作完整、主体稳定、镜头可用的版本；再把提示词与用户输入动作的对应关系交给开发团队，由后端写入小程序的视频生成服务。
